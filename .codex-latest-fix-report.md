# Latest fixes report

## Outcome

- Replaced the layered, world-space star buffer with one bounded WebGL1 full-screen procedural starfield. Its `count` and `seed` are deterministic configuration uniforms; camera zoom does not affect nominal screen-space density. The scene still adds exactly one `StarfieldEntity`.
- Added the default-on **Heliopause: On/Off** button to the existing Scene display controls. It controls only the halo, independently of Journey and Labels.
- Journey Fit now frames the Sun-centered envelope of the birthday-Earth origin and live endpoint. It no longer imports a static body/probe roster extent, starts at the early journey extent, and grows with DAM.
- Confirmed the existing DAM contract: `distanceTraveledKm(365.25) === 940_000_000`, equivalent to approximately 29.77 km/s. The rate was not changed.
- The development renderer remains `circle` (`OUTWARD_JOURNEY_RENDER_MODE = "circle"`).
